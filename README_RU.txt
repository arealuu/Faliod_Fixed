Faliod — мод для Minecraft Java 1.21.1 / NeoForge 21.1.266

Биом:
- ID: faliod:faliod
- Не добавлен в источники обычной генерации мира.
- Назначить биом можно командой:
  /fillbiome ~-10 ~-10 ~-10 ~10 ~10 ~10 faliod:faliod

Эффекты в биоме:
- Через 3 секунды появляются тёмные частицы.
- Через 6 секунд игрок получает 1 единицу урона каждую секунду.
- Через 7 секунд накладывается слепота и проигрываются тревожные звуки.
- Через 15 секунд игрок погибает напрямую.
- После пребывания в биоме не менее 1 секунды использование хоруса отменяется и убивает игрока.
- Энд-перлы, появившиеся внутри биома, удаляются.
- Лодки, появившиеся внутри биома, уничтожаются и оставляют 1–2 палки.

Сборка на Windows:
1. Установите Java 21 (JDK).
2. Распакуйте архив.
3. Откройте терминал в папке проекта.
4. Выполните: gradlew.bat build
5. JAR появится в build\libs\faliod-1.0.0.jar

Сборка на Linux/macOS: ./gradlew build

GitHub Actions настроен на автоматическую сборку и публикацию JAR как артефакта
при push, pull request или ручном запуске workflow_dispatch.

ВАЖНО: в этой среде Gradle не смог скачать дистрибутив с services.gradle.org
(UnknownHostException). Поэтому этот проект пока не прошёл компиляцию и тест
в Minecraft; не считайте его готовым проверенным JAR.
